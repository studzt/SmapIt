# Contributing to SmapIt

Thanks for you interest in improving this project!
This guide will help you to contribute effectively.

## How can you contribute
There are several ways that you improve this project:

**1. Translations**<br>
You can help this project by translating it via crowdin!
To access it, just [click here](https://crowdin.com/project/smapit).

**2. Bug report**<br>
You can open an issue with a clear description and, if possible, steps to reproduce it.

**3. Request features**<br>
Got an idea for a new feature or improvement? Feel free to open an issue and explain your suggestion.

**4. Submit Pull Requests**<br>
If you want to add a new functionality or fix something, you can send a Pull request.
If you want to send a pull request, follow the instructions below:

----

# How to send a pull request
### 1- Fork and clone the repository
Fork and then clone the repository:
```
git clone git@github.com:your-username/SmapIt.git
```

### 2- Create a new branch
Before making changes, create a separate branch:
```
git checkout -b your-branch-name
```
Name your branch according to the change you're making.<br>
For example: `fix-issue-02`, `add-new-button`, etc.

### 3- Make your changes
Implement the changes, test, and make sure everything is working correctly.

### 4- Commit your changes
Write clear commit messages describing what you changed and why.

### 5- Open a pull request
Push your branch to your fork and open a pull request. Explain your changes clearly in the PR description.

----

## Rules and Best Practices
**Be respectful**<br>
Treat everyone with respect and kindness. Constructive and positive contributions are welcome.

**Follow the code style**<br>
Make sure your changes match the coding style used in the project.

**Write and run tests**<br>
Ensure your code is well-tested and doesn't introduce bugs.
