## ❓ What is?
SmapIt is a tool that helps you adding some extra functions to Smapi.
It includes:
- Automatic SMAPI updater
- Hide SMAPI console
- Profiles

More functionalities will be added soon! (its in beta version)

## ⚙️ Installation
To use SmapIt you need Windows 10+
64 bits

You can download SmapIt using [winget](https://winstall.app/apps/SmapItProject.SmapIt), by running this command in your command prompt:

```batch
winget install SmapItProject.SmapIt
```
---
If you want to install it manually, first download the [.NET Desktop Runtime 8.0.16](https://builds.dotnet.microsoft.com/dotnet/WindowsDesktop/8.0.16/windowsdesktop-runtime-8.0.16-win-x64.exe).<br>
After that, download the [latest release](https://github.com/studzt/SmapIt/releases/latest) of SmapIt, run it and just follow the app instructions.

> [!IMPORTANT]
> Windows Smartscreen may show a popup when running SmapIt for the first time because it is a new and not signed app.<br>
> Signing an application costs hundreds of dollars per year.<br>
> This does not mean the program is being detected as malicious, its just a new program.<br>
> To dismiss it, just click on "More info" and then "Run anyway".
