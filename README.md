## ❓ What is?
SmapIt is a tool that helps you adding some extra functions to Smapi.
It includes:
- Automatic SMAPI updater
- Hide SMAPI console

More functionalities will be added soon! (its in beta version)

## ⚙️ Installation
You can download SmapIt by clicking [here](https://github.com/studzt/SmapIt/releases/latest) or by going to releases pages in this repository.
After installing the manager, open it and just follow the app instructions.

To use SmapIt you need Windows 10+
64 bits

You also need the [.NET Desktop Runtime 8.0.16](https://builds.dotnet.microsoft.com/dotnet/WindowsDesktop/8.0.16/windowsdesktop-runtime-8.0.16-win-x64.exe).
Be sure you have it installed before using SmapIt.

> [!IMPORTANT]
> Windows Smartscreen may show a popup when running SmapIt for the first time because it is a new and not signed app.<br>
> Signing an application costs hundreds of dollars per year.<br>
> This does not mean the program is being detected as malicious, its just a new program.
